### 🚀 Featured Projects

#### 🧠 [TubeMind AI](https://github.com/Omkar-narsale/TubeMind-AI): chat with any YouTube video

A Chrome extension that uses Retrieval-Augmented Generation to turn a YouTube video into something you can question and study from.

- Multi-turn chat with streaming responses
- Pipeline: transcript retrieval → semantic chunking → Sentence Transformers → FAISS search
- Summaries, study notes, key takeaways, and timestamp citations that jump to the exact moment
- Groq + Llama 3.3 70B for low-latency inference

#### 📚 [LangChain Smart Study Assistant](https://github.com/Omkar-narsale/LangChain-Smart-Study-Assistant): document to study kit

Upload a TXT, PDF or DOCX (or paste text) and get a summary, key points, quiz and flashcards in one pass, generated in parallel with LangChain `RunnableParallel`. Everything exports as a single study report. Runs on TinyLlama-1.1B via HuggingFace.

#### 🚦 [Road Safety Analytics](https://github.com/Omkar-narsale/Road-Safety-Analytics-PowerBI): Power BI dashboard

Analyses road accident data to find trends, causes and high-risk factors.

- Executive view: total accidents, casualties, fatality rate, monthly trends
- Root-cause breakdowns by weather, road surface, lighting and collision type
- Highest-risk time, vehicle type, and driver age vs. speed limit
- Data cleaned with Pandas, modelled in Power BI with DAX KPIs, slicers and custom navigation
